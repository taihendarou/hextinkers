Batman Forever é um jogo de ação para Super Nintendo baseado no filme de 1995, conhecido no Brasil como **Batman Eternamente**. O jogador controla Batman ou Robin em uma aventura que combina combates, exploração e elementos de plataforma.

O jogo apresenta personagens com gráficos digitalizados a partir de atores reais e permite que dois jogadores enfrentem os desafios juntos. Com esta tradução, os textos e gráficos estão disponíveis em português, incluindo o título adaptado para **Batman Eternamente**.

## Sobre a tradução

O projeto começou em setembro de 2025, a partir de uma proposta do ByFTR de traduzir Batman Forever para o português. A versão 1.0 foi lançada em **22 de outubro de 2026**.

A tradução inclui textos, menus e gráficos em português, com suporte a letras minúsculas e caracteres acentuados. A fonte também recebeu ajustes visuais para melhorar a apresentação dos textos.

### Detalhes técnicos

Um dos desafios do projeto foi trabalhar com a compressão RNC utilizada pelo jogo. Para comprimir e descomprimir os dados, utilizamos a ferramenta `rnc_propack_source`. O trabalho também serviu como oportunidade para estudar melhor esse algoritmo e a organização dos dados comprimidos na ROM.

A fonte foi expandida para incluir letras minúsculas e acentos. Como algumas fontes utilizam caracteres de 8x8 pixels, sem espaço para colocar os acentos em um tile acima, foram criadas versões das letras minúsculas com os acentos incorporados ao próprio caractere.

O patch deve ser aplicado à ROM original da versão americana, sem outras modificações. Confira os dados abaixo para identificar a ROM compatível.

- **Database match**: Batman Forever (USA)
- **Database**: No-Intro: Super Nintendo Entertainment System (v. 20210222-050638)
- **File/ROM SHA-1**: `8284E6814D6A01A191E82B107EB46570E3ECD9F3`
- **File/ROM CRC32**: `D9B5E9CF`

### Como aplicar

1. Acesse o [aplicador de patches online](https://www.romhacking.net/patch/){:target="_blank"}.
2. Selecione sua ROM original e o arquivo BPS da tradução.
3. Aplique o patch e salve a ROM resultante.
4. Abra a ROM traduzida em um emulador compatível com Super Nintendo.
